# research/

Research the person asked for: one folder per topic, a cited report, its sources, and each researcher's notes

Layout: `research/<topic>/{README.md, brief.md, sources.md, notes/<writer>--<subquestion>.md}`

Start a topic with `library.mjs new-topic <slug>`. Each researcher writes only its own files in notes/. One synthesizer writes README.md and sources.md. Every claim in README.md cites a source id like [S3] defined in sources.md.

Written by the librarian from `~librarian/policy.json`; it is not regenerated once it exists, so edit it freely.
